GitHub Mobile Web Link Deployment

Provide this web link to your sales team so they can log visits from their phone browser

This application is 100% static and requires zero build tools. To deploy it to GitHub:

  1. Initialize git and push this repository to GitHub
  2. In your GitHub repo, go to Settings -> Pages
  3. Under Build and deployment, set Source to Deploy from a branch and select main / root
  4. GitHub will provide you with a live HTTPS link (e.g. https://username.github.io/sales-erp) that your sales team can open on any iPhone or Android phone!
